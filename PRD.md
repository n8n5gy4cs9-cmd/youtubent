## 1. What is it
A small desktop app that turns a YouTube video or Short into a **screenshot storyboard**, so you can tell
the story of a video without watching it. Main use: send a hilariously incomplete summary to a friend.
Personal fun project. **Keep it simple. No over-engineering. It just works and it's fun.**

## 2. Platforms
- **Now:** macOS, Apple Silicon (M1 Max), packaged as `.app` with PyInstaller.
- **Later (keep code portable, optional):** Windows, Linux. No mac-only APIs in `core/`; use `pathlib`, no hardcoded paths.

## 3. Tech stack
| Area | Choice |
|---|---|
| Language | Python 3.14 (venv, arm64). Dev sandbox may be 3.13 — code must work on both |
| GUI | PySide6 6.x (dark custom QSS theme) |
| Packaging | PyInstaller → `.app` |
| Tests | pytest |
| **Added** yt-dlp | resolve + download the video (low-res mp4 is enough for screenshots) |
| **Added** imageio-ffmpeg | bundled ffmpeg binary → grab exact frames (`-ss` seek), no system install needed |
| **Added** Pillow | compose storyboard grid, captions, export PNG/JPG/PDF; also generates the sprites |

Stack items from the template not needed here (playwright, httpx, selectolax) are intentionally left out.

## 4. Features (MVP = all of these)
1. **Video import** — paste URL (watch / youtu.be / shorts / embed) → load. Shows title + duration, downloads a small preview copy into a cache dir.
2. **Automatic points** — settings: count N, mode `even` | `random`. Even = centered in N equal slices. Random = one random time per slice (still chronological). Re-generate any time.
3. **Timeline editor** — horizontal timeline with draggable markers, exact timestamps, add (at playhead / at clicked place), delete, nudge ±0.1s/±1s, type an exact time `mm:ss.s`.
4. **Frame preview** — large preview of selected point; changing the time updates the frame (debounced). Frame scrubbing slider.
5. **Gallery** — thumbnail strip/grid of all points; click = select, drag = reorder (display order), ✕ = remove, checkbox = include in storyboard.
6. **Storyboard generator** — chronological grid (columns 1–6), cell size, gap, theme (dark/light/…), title header, optional timestamp badges, per-frame captions + a "funny commentary" caption box.
7. **Captions** — per point: caption text (editable in side panel and in gallery). Optional random "joke caption" button using a built-in list of silly captions (offline, no AI).
8. **Export** — PNG, JPG, PDF. Copy to clipboard. Save-as dialog. "Reveal in Finder".
9. **Project save/load** — `.ytb` JSON file (url, points, captions, settings). Autosave last session.
10. **Shorts** — vertical videos work (cells adapt to aspect ratio).

## 5. UX
- Dark pro look: charcoal greys `#1b1c1f` bg, `#25262b` panels, accent coral-red `#ff4d5e` (a nod to YouTube, but not the logo).
- Layout:
  - **Top bar:** logo sprite, URL field, Load button, point count spinner, mode (Even/Random), Generate button.
  - **Center:** big frame preview (left) + side tabs (right): *Point* (time + caption), *Export* (layout settings).
  - **Below preview:** timeline panel.
  - **Bottom:** gallery strip.
  - **Status bar:** progress + friendly messages.
- Fun: emoji/sprite icons, playful empty state ("Paste a link. Skip the video."), random loading messages, confetti-free (keep simple).
- Keyboard: `Space` add point at playhead, `Del` delete selected, `←/→` prev/next point, `Shift+←/→` nudge 1s, `Cmd+E` export, `Cmd+O/S` open/save project.
- Everything long-running (download, frame grab, export) runs off the UI thread (QThreadPool), UI never freezes.

## 6. Sprites (all generated by code, `tools/make_sprites.py`, Pillow, no external art)
Output to `assets/sprites/` (PNG, 2x size 64px + 32px) and `assets/app/` (icon 1024 png, `.icns` on mac, `.ico`):
- App icon (film-strip frame w/ play/skip look), logo wordmark
- Toolbar/UI icons: load, generate, add, delete, play, pause, prev, next, export, save, open, copy, shuffle/random, even, image, pdf, caption, clock, reorder, check, close, warning, folder, zoom
- Empty-state illustration, loading spinner frames (8), marker pin sprite, playhead sprite, joke/emoji sticker (poop-free, just stars/sparkles)
Style: flat, rounded, light-grey glyphs (`#e6e7ea`) on transparent, accent versions in coral. Consistent 2px stroke look.

## 7. Architecture
```
youtubent/
  app.py                 entry point
  core/
    models.py            Project, Point dataclasses, JSON (de)serialize
    urls.py              extract video id / validate url
    downloader.py        yt-dlp wrapper (info + download low-res mp4)
    frames.py            ffmpeg frame grab -> PIL.Image
    points.py            even/random generation, helpers (clamp, sort, format/parse time)
    storyboard.py        Pillow compose + export png/jpg/pdf
    captions.py          silly caption list
    settings.py          QSettings-free tiny json settings in user dir
  ui/
    theme.py             QSS + palette + icon loader
    main_window.py       layout + wiring
    preview.py           big frame viewer
    timeline.py          custom-painted timeline widget
    gallery.py           thumbnail list widget
    side_panels.py       Point panel + Export panel
    workers.py           QRunnable workers + signals
tools/make_sprites.py    generates every sprite
assets/                  generated sprites (committed)
tests/                   pytest (core only + offscreen smoke)
guide.html               user guide
build_mac.sh / YoutubeNt.spec   PyInstaller packaging
```
Rules: `core/` has **no Qt imports** (testable, portable). UI only calls core through workers.

## 8. Non-goals
No accounts, no cloud, no AI summarizing, no video playback/audio, no playlist support, no auto-update.

## 9. Acceptance
- Paste a URL → points appear in <~30s on normal connection → storyboard exports to PNG and PDF.
- Can add/delete/move/type-time for every point and see the right frame.
- `pytest` passes. `python -m youtubent` launches. `./build_mac.sh` produces `dist/Youtubent.app` on a Mac.
