# Youtuben't

Turn a YouTube video or Short into screenshots / a funny storyboard without watching it.
See `guide.html` for usage, `PRD.md` for the plan, `task.md` for progress.

```
python3 -m venv .venv && source .venv/bin/activate   # after activating, `python` works
pip install -r requirements.txt
python -m youtubent
```
Build the Mac app: `./build_mac.sh`. Tests: `python -m pytest`.
