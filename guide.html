Tell the story of a video without watching it.

1. The 5-step flow

  1. Paste a YouTube link (video or Short) in the top bar and hit Load. The first time, the video is downloaded in low-res (video only) to a cache — later loads are instant.
  2. Generate shots: choose how many (Shots) and Evenly spaced or Random. It runs automatically after loading; press Generate again for a fresh set.
  3. Edit: click a marker or thumbnail to preview it. Drag markers on the timeline, type an exact time, nudge ±0.1s / ±1s, add or delete points.
  4. Caption (optional): write something funny, or hit Random joke. Untick a thumbnail to leave it out.
  5. Export (right panel, Export tab) and press the big red button.

2. Export modes

ModeYou get
Separate PNG frames defaultA folder of numbered PNGs: my_video_001.png, _002.png… No storyboard.
Storyboard (PDF)One stylized page: title, grid, timestamps, captions. Perfect to send to a friend.
Storyboard (PNG)Same storyboard as a single image.

Storyboard options: columns, frame size, gap, theme (dark / midnight / light / paper), custom title, and toggles for title, timestamps and captions. Frames are always in chronological order.

3. The timeline

  • Click empty space to move the playhead and preview that moment.
  • Drag a marker to move a shot. Release to refresh its thumbnail.
  • Double-click empty space to add a shot there. Or press Space to add one at the playhead.
  • Greyed markers are shots excluded from the export.

4. Shortcuts

SpaceAdd shot at playhead
DeleteDelete selected shot
← →Previous / next shot
Shift+← →Nudge selected shot by 1 second
⌘EExport
⌘O / ⌘SOpen / save project (.ytb)

Typing in a text box takes priority over shortcuts, so spaces and arrows work normally while writing captions.

5. Projects & autosave

Save your points, captions and export settings as a .ytb file. The app also reopens your last session automatically.

6. Running it

From source (macOS, Apple Silicon):

python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m youtubent

Build the .app: ./build_mac.sh → dist/Youtubent.app

Regenerate all icons/sprites: python tools/make_sprites.py

Tests: python -m pytest

7. Troubleshooting

  • “Can't reach YouTube” — check your connection. Cached videos still load offline.
  • Download fails suddenly — YouTube changes often. Update the downloader: pip install -U yt-dlp.
  • Private / age-restricted / members-only videos can't be loaded.
  • Cache lives in ~/Library/Application Support/Youtubent/cache. Delete it any time to free space.
  • Wrong frame? Frames are exact for the time shown; nudge by 0.1s to find the perfect moment.
